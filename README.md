# SSAO 核采样与降噪

一个能在深度缓冲上做遮蔽估计并抑制噪声的 SSAO 实现，仅使用 Python 标准库。

约定：深度值越大离相机越远；AO ∈ [0, 1]，1 表示无遮蔽。

## 保留签名

- `DepthBuffer`
- `sample_kernel(count, radius, seed)`
- `compute_ao(buf, kernel)`
- `denoise(ao, sigma_s, sigma_r)`

## 实现要点

### 采样核（`sample_kernel`）

- 半径：黄金比例低差异序列经平方根缩放到 `[0, radius]`，圆盘内面积均匀。
- 旋转：相邻样本间隔黄金角（≈2.39996 rad），整体再按 `seed` 确定性旋转。
- **嵌套性**：`count=N` 的核是 `count=N+1` 的核的前缀——样本数变化只增删样本，
  已有样本位置不动，因此结果不会跳变（实测 8/16/32/64 样本的平均遮蔽两两相差 < 0.01）。
- 同样的 `(count, radius, seed)` 永远得到同样的核，无随机状态。

### 遮蔽估计（`compute_ao`）

- 样本深度 < 中心深度且深度差不超过边缘阈值时计入遮蔽，
  权重为 `深度差 / 边缘阈值` 的连续值（不用二值计数，避免样本数变化时的量化跳变）。
- **边缘无黑边判据**：中心与样本的深度差 > `EDGE_DEPTH_RATIO`（0.1）× 场景深度范围时，
  判定样本属于前景另一物体，直接忽略，不计入遮蔽。
  因此深度突变的边缘（如阶梯）两侧 AO 保持 ≈ 1.0，不产生黑边。

### 降噪（`denoise`）

- 双边滤波：空间高斯（`sigma_s`）× 值域高斯（`sigma_r`）。
  AO 差值大的像素（边缘两侧）权重指数衰减，边缘不被抹平。
- **边缘保留度**：定义为降噪后/前全图梯度幅度和之比，1.0 为完全保留；
  在 AO 阶梯（0.4 | 0.9）上实测边缘对比度保留 ≥ 80%（见 `test_denoise_preserves_edges`）。
- **均值不漂移**：滤波后把整体均值平移回滤波前均值，平均遮蔽值零漂移。

### 边界输入

- 全平面：AO 恒为 1.0。
- 纯阶梯：边缘样本被边缘判据忽略，AO 恒为 1.0，无黑边。
- 深度全为 0：无任何深度差，AO 恒为 1.0。

三种输入均有确定结果，且同样输入两次运行输出逐字节一致。
